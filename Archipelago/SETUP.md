# DTA Archipelago setup

1. Copy `dta.apworld` into Archipelago's `custom_worlds` folder.
2. Start the DTA Randomizer from the DTA installation root.
3. Open the Archipelago tab, configure server and slot, and export the YAML/run manifest through the existing launcher flow.
4. Generate the multiworld with the matching APWorld.
5. Connect from the launcher's Archipelago tab before starting missions.

The APWorld and launcher version must match. Live end-to-end multiworld behavior still needs verification.

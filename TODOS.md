New Game mode idea
------------------------------

Implementation status: deferred. The design will be completed in the Mental Omega Randomizer first. DTA contains no active Shop mode.
The levels will be divided into 3 categories:

•Easy, Medium, and Hard. Easy will be worth 1 point, Medium 2 points, and Hard 3 points (reward points) - This can be adjusted and should be the "currency" which allows the user to buy unlocks in the shop or buy upgrades and buffs for the units they already have.

•The points earned from the levels can be used in the shop section of the main launcher to unlock new technologies and units (for example: 1 point to unlock Conscript, 3 points for Rhino Tank, or 2 points for Sniper+Pyro).

The Level cards have different Difficulties as suggested So the player can choose easy medium or hard with what they got
IF they fail the run "ends" and they need to generate a new seed where they start from the beginning, also T1 random units AND defensis should always be given to the player at the start so they can even progress harder maps if they wanted to. Kinda like in Chaos mode with the T1 unlocks at the start. The minimum of missions that need to be done is 10. We can later adjust more to this idea.
